# Страница роли

## Цель

Страница роли заменяет «класс» из фэнтезийных справочников и помогает выбрать архетип
персонажа без раскрытия полной механики основной книги.

## Структура

1. Русское и английское название роли.
2. Метаданные: система, редакция и источник.
3. Зелёная CRT-заглушка вместо иллюстрации.
4. Карточка специальной способности: русское и английское название, описание и диапазон рангов.
5. Полоса развития специальной способности по рангам и пояснение механики роста.
6. Список профессиональных навыков.
7. Секции Markdown: «О роли», «Специальная способность», «В группе», «Вопросы для концепции».
6. Правовое уведомление и ссылка на основную книгу.

## Заглушки вместо изображений

Заглушка строится в CSS и содержит код роли, прицельную сетку, сканирующую строку и
геометрический силуэт. Она не имитирует официальное оформление, не использует внешние файлы
и позднее может быть заменена лицензированной иллюстрацией через отдельное поле frontmatter.

## Публикация

- Все текущие роли остаются `draft` и показываются только в режиме разработки.
- После редакторской и юридической проверки роль переводится в `review`, затем в `published`.
- Ранги, способности и профессиональные навыки сверяются с разрешённым PDF и проходят
  редакционную проверку перед публикацией.
