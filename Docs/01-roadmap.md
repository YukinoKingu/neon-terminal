# План разработки Cyberpunk 2020 Wiki

## Принципы

- Сначала создаётся быстрый статический справочник, затем интерактивные функции.
- Контент отделён от интерфейса и проверяется схемами при сборке.
- Astro формирует страницы, Vue используется только для интерактивных островов.
- TypeScript в строгом режиме обязателен для конфигурации, схем, утилит и Vue-компонентов.
- Архитектура сразу учитывает будущую Cyberpunk RED, но не реализует её заранее.
- Каждая итерация заканчивается рабочей сборкой и проверенным набором контента.

## Этап 0. Проектирование

### Результат

Согласованные требования, структура контента и безопасные правила публикации.

### Задачи

- Зафиксировать границы первой версии.
- Утвердить редакцию Cyberpunk 2020 2.01.
- Определить правила русской терминологии.
- Утвердить структуру Markdown-файлов.
- Определить допустимый объём пересказа правил и игровых данных.
- Выбрать рабочее название проекта.

## Этап 1. Технический фундамент

Пустой, но готовый к расширению сайт с Astro и Vue.

### Задачи

### Проверка

## Этап 2. Контентный фундамент

### Результат

Markdown превращается в типизированные и проверяемые страницы.

### Задачи

- Создать Astro Content Collections для всех типов сущностей.
- Описать общие и специализированные схемы frontmatter.
- Добавить шаблоны Markdown в `Docs/Templates`.
- Реализовать проверку уникальности идентификаторов и ссылок.
- Добавить статусы материалов: `draft`, `review`, `published`.
- Создать словарь терминов с русским и английским названием.
- Добавить тестовые материалы каждого типа.

### Проверка

- Некорректный frontmatter останавливает сборку с понятной ошибкой.
- Все внутренние ссылки разрешаются по стабильным идентификаторам.
- Черновики не попадают в production-сборку.

## Этап 3. MVP справочника

### Результат

Пользователь может вручную создать персонажа, переходя по связанным страницам справочника.

### Разделы

- Пошаговое создание персонажа.
- Роли и специальные способности.
- Характеристики и производные значения.
- Навыки и их связь с характеристиками.
- Полный Lifepath из основной книги.
- Начальные деньги и экономика создания персонажа.
- Оружие.
- Броня.
- Снаряжение.
- Киберимпланты, человечность и эмпатия.

### Интерфейс

- Главная страница системы.
- Каталог разделов.
- Страница списка для каждого типа сущностей.
- Универсальная карточка материала.
- Перекрёстные ссылки между ролями, навыками, снаряжением и правилами.
- Хлебные крошки и локальная навигация по разделу.
- Печатная версия страниц без декоративного интерфейса.

### Проверка

- Весь путь ручного создания персонажа доступен только через опубликованные страницы.
- Русские и английские названия отображаются единообразно.
- Все страницы доступны по стабильным URL.
- Сборка не содержит битых внутренних ссылок.

## Этап 4. Наполнение и редактура

### Результат

Справочник наполнен оригинально сформулированными материалами по основной книге правил.

### Порядок наполнения

1. Термины, характеристики и базовые правила создания.
2. Роли и специальные способности.
3. Навыки.
4. Lifepath.
5. Экономика и начальные средства.
6. Оружие и броня.
7. Снаряжение.
8. Киберимпланты и человечность.
9. Связи между материалами и итоговая редактура.

### Редакционный процесс

- Автор создаёт или обновляет отдельный Markdown-файл.
- Сборка автоматически проверяет структуру.
- Материал получает статус `review`.
- Редактор проверяет терминологию, механику и оригинальность формулировки.
- После проверки материал переводится в `published`.

- Реализовать Vue-диалог глобального поиска.
- Поддержать поиск по русским, английским названиям и псевдонимам.
- Добавить фильтры для навыков, оружия, брони, снаряжения и киберимплантов.
- Синхронизировать фильтры с URL.
- Добавить управление с клавиатуры.

## Этап 6. Будущие возможности

- Пошаговый конструктор персонажа.
- Генерация и печать листа персонажа.
- Локальное сохранение незавершённого персонажа.
- Аккаунты, серверное хранение, избранное и заметки.
- Поддержка Cyberpunk RED как отдельного пространства `/red/...`.
- Сравнение терминов и механик между системами.

## Критерии готовности первой версии

- Опубликованы все разделы, необходимые для ручного создания персонажа.
- Используются только материалы основной книги правил Cyberpunk 2020 2.01.
- Контент хранится в Markdown и проходит автоматическую валидацию.
- Страницы работают без обязательной клиентской гидратации.
- Интерфейс адаптивен, доступен с клавиатуры и пригоден для печати.
- На сайте размещено заметное уведомление о неофициальном статусе.
- Production-сборка проходит без ошибок, черновиков и битых ссылок.
