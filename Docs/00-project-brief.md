# Cyberpunk 2020 Wiki — описание проекта

## Статус документа

Черновик. Обновляется по мере уточнения требований.

## Цель

Создать русскоязычный онлайн-справочник по настольной ролевой системе Cyberpunk 2020, вдохновлённый удобством TTG Club, но с самостоятельным интерфейсом в стилистике терминала.

Первый этап охватывает только Cyberpunk 2020. Поддержка Cyberpunk RED рассматривается как отдельный будущий этап и не должна усложнять первую версию.

## Принятые решения

- Первая поддерживаемая система — Cyberpunk 2020, редакция 2.01 основной книги правил.
- Основной язык интерфейса и описаний — русский.
- Оригинальные английские названия отображаются рядом с русскими.
- Первая версия использует только основную книгу правил без дополнений.
- Начальный объём контента — справочник со всем необходимым для ручного создания персонажа.
- Таблицы Lifepath входят в первую версию.
- Контент хранится в Markdown и изменяется через Git.
- Astro отвечает за маршруты, сборку и статический контент.
- Vue используется для интерактивных элементов.
- Весь прикладной код и конфигурация пишутся на TypeScript; Vue-компоненты используют `<script setup lang="ts">`.
- Глобальный поиск и фильтры нужны, но не входят в первую итерацию.
- Пользовательские аккаунты, избранное, заметки и сохранённые персонажи откладываются на будущее.
- Интерфейс получает самостоятельный визуальный стиль терминала Cyberpunk 2020.
- Предполагаемый вариант размещения — собственный сервер, окончательное решение не принято.
- Подтверждённая редакция основной книги — Cyberpunk 2020 2.01.
- Основная визуальная тема — зелёный CRT-терминал.
- Рабочий вариант названия — `NEON//TERMINAL`, ожидает окончательного утверждения.

## Предварительный подход

- Генерировать справочные страницы статически из Astro Content Collections.
- Хранить отдельные сущности в отдельных Markdown-файлах с проверяемым frontmatter.
- Использовать Astro-компоненты для основного интерфейса и Vue islands только там, где требуется состояние или интерактивность.
- Сохранить возможность добавить серверные функции позднее, не делая backend обязательным для первой версии.

## Отложенные возможности

- Глобальный полнотекстовый поиск.
- Фильтрация и сортировка больших каталогов.
- Интерактивный конструктор и генератор листа персонажа.
- Личные кабинеты.
- Избранное и пользовательские заметки.
- Хранение персонажей.
- Поддержка Cyberpunk RED.

## Ограничения наполнения

- Для Cyberpunk 2020 не найдено единой официальной русской локализации. Терминология формируется по наиболее распространённым русскоязычным вариантам с обязательным сохранением английских названий.
- Тексты пишутся своими словами и проходят редактуру; сторонние фанатские переводы не копируются.
- Нельзя копировать художественное оформление, логотипы, шрифты и иллюстрации из книги без разрешения.
- Справочник должен оставаться бесплатным и содержать уведомление о неофициальном статусе.
- Следует запросить у R. Talsorian Games письменное разрешение, если проект будет публиковать полный каталог игровых характеристик и таблиц.

## Открытые вопросы

- Рабочее и публичное название проекта.
- Выбор CSS-инструментов и окончательная визуальная концепция.
- Вариант размещения и серверный адаптер Astro.
- Лицензирование собственного кода и созданных проектом текстов.
