# Реестр спорной терминологии

## Назначение

Документ собирает термины, для которых в русскоязычном сообществе используются разные варианты.
До редакторского решения карточки остаются в статусе `draft` и сохраняют английское название.

## Источники для сверки

- оригинальная основная книга Cyberpunk 2020 редакции 2.01;
- официальный [раздел загрузок R. Talsorian Games](https://rtalsoriangames.com/downloadable-content/);
- официальный [лист персонажа Cyberpunk 2020](https://rtalsoriangames.com/wp-content/uploads/2013/01/cyberpunk2020.pdf);
- несколько независимых русскоязычных источников для оценки распространённости перевода.

## Процесс принятия термина

1. Сверить английское написание с легальным первичным источником.
2. Найти варианты минимум в двух независимых русскоязычных источниках.
3. Выбрать наиболее понятный и распространённый вариант.
4. Остальные варианты записать в `aliases`.
5. Обновить все связанные карточки одним pull request.
