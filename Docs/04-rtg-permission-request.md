Permission question for a free Cyberpunk 2020 reference web app

## Текст на английском

Hello R. Talsorian Games team,

## Смысловой перевод

Здравствуйте! Я разрабатываю бесплатный неофициальный русскоязычный веб-справочник для владельцев основной книги Cyberpunk 2020 редакции 2.01.

Проект не будет использовать официальные логотипы, иллюстрации, шрифты, сканы или оформление книги. Русские описания будут написаны заново в форме кратких сводок, а английские названия нужны для сопоставления с оригиналом.

Первая версия помогает вручную создать персонажа и содержит роли, характеристики, навыки, Lifepath, начальные средства, оружие, броню, снаряжение и киберимпланты только из основной книги. Сайт останется бесплатным и будет содержать обязательное уведомление о неофициальном статусе.

Мы просим уточнить, можно ли публиковать структурированные игровые значения и кратко сформулированные результаты таблиц Lifepath без полного описательного текста. Если такой объём слишком велик, просим указать допустимый формат бесплатного веб-помощника.
