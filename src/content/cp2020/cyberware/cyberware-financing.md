Один из трёх работодателей — секретная военная организация, организованная преступность или корпорация — оплачивает до **10 000 eb** кибероснащения без платы со стороны персонажа. Взамен служба длится неопределённо долго.

Рефери выбирает один или несколько способов контроля и может не раскрывать их игроку:

| Контроль | Игровое содержание |
|---|---|
| Заложник | Важный для персонажа человек удерживается работодателем. |
| Шантаж | Работодатель хранит компромат. |
| Саботированный чип | Командный сбой в чипе может убить носителя. |
| Наблюдение | Импланты передают работодателю сведения о персонаже. |
| Команда убийства | Услышанное кодовое слово вынуждает совершить убийство без возможности себя остановить. |
| Защита сотрудников | Персонаж не может сознательно причинить вред члену организации; попытка вызывает нарастающую боль, затем остановку сердца и смерть. |
| Дистанционный детонатор | Инертный пакет взрывчатки не обнаруживается сканерами; попытка найти его с вероятностью 60% активирует заряд. |
