## Движение и масштаб

- За каждый Сетевой раунд/ход нетраннер перемещается на **5 пространств**; движение — только через стороны клеток, не по диагонали.
- Масштаб: мировая карта — **около 2,590 км² на пространство**; городская карта — примерно дюжина кварталов; одна клетка городской карты разворачивается в карту подсети; клетка подсети — примерно несколько квадратных метров (позднее карта описана как 20×20 клеток по 10 м).
- На мировой карте переход возможен только между точками LDL в радиусе движения; нельзя закончить «прыжок» в океане без LDL.

## Дальние тарифы

$$\text{Цена LDL} = \text{число пространств} \times 0.2\ \text{ED/EB} \times \text{число раундов в Сети}$$

Пример Найт-Сити → Лондон: 8 пространств × 0.2 × 2 раунда = **3.2 ED/EB**.

## Уровень безопасности LDL

Для бесплатного/ложно-локального перехода бросить **1D10 ≥ Уровень безопасности LDL**. При провале бросить 1D6:

| 1D6 | Результат |
|---:|---|
| 1 | Линия отрезана; звонок нужно оплатить |
| 2 | Отключение; Сетевой Дозор получает Сетевой код доступа; ожидается визит в реальном мире |
| 3 | Сетевые копы пытаются арестовать: дополнительный 1D6 |
| 3 → 1–2 | Штраф **1D6 × 100 ED/EB** |
| 3 → 3–5 | Побег; **1D6+1 дней** патрулирования области |
| 3 → 6 | Побег, но ВсеСетевой розыск |

## Трассировка

Суммировать Значения трассировки всех пройденных LDL. Программа успешно отслеживает источник, если:

$$1D10 + \text{Сила программы} \ge \sum \text{Значений трассировки LDL}$$

Пример: Солт-Лейк 1 + Денвер 2 + Новый Орлеан 3 + Гавана 3 + Богота 4 + Рио 2 = **15**; Адской гончей Силы 6 нужен естественный 9–10.

## Городские системы и случайные встречи

| Обозначение | Типичная защита / владелец |
|---|---|
| Серый | только Обнаружение/Тревога; городские органы, университеты, малый бизнес |
| Уровень 1 | Обнаружение/Тревога и Анти-ЛЁД; малые корпорации, полиция, крупный частный бизнес |
| Уровень 2 | Анти-ЛЁД и Анти-системные; средние корпорации, очень крупный частный бизнес |
| Уровень 3 | несмертельные Анти-личностные; крупные корпорации/правительства штатов |
| Чёрный | смертельные и несмертельные средства; транснациональные корпорации, ЦРУ и подобные учреждения |

При ожидании отключённой системы: 1D6 — **1–2 никого; 3 проходящая программа; 4 дружественный нетраннер; 5 враждебный нетраннер; 6 нетраннер Сетевого Дозора**.

## Подсеть и Меню

Подсеть — карта 20×20 клеток (A–T, 1–20), приблизительно 12 городских кварталов, клетки по 10 м. В ней раннер движется 5 клеток/ход по прямым линиям; препятствие нужно обойти, открыть или разрушить.

| Команда | Правило |
|---|---|
| ОБНАРУЖЕНИЕ УДАЛЁННОГО ПОДКЛЮЧЕНИЯ | из реального пространства сканирует радиус **400 м**, выводит все сетевые удалённые подключения, местоположение и тип |
| УПРАВЛЕНИЕ УДАЛЁННЫМ ПОДКЛЮЧЕНИЕМ | находит подходящий Контроллер; захват при **1D10 ≤ Сила Контроллера**, максимум 10; после успеха доступны все штатные функции устройства |
| ВХОД / ВЫХОД | ВХОД переносит в Сеть; ВЫХОД успешен на **1D10 ≤ 8**; удерживающие программы могут блокировать отключение/выдёргивание проводов 1D6 раундов |
| ЗАПУСТИТЬ ПРОГРАММУ | немедленно запускает выбранную программу из Памяти |
| СВЯЗЬ НА ДАЛЬНЕЕ РАССТОЯНИЕ | для ложного местного тарифа: **1D10 ≥ Уровень безопасности LDL** |
| КОПИРОВАТЬ | копирует доступный файл/программу в свободную Память деки |
| СТЕРЕТЬ | удаляет файл/программу из деки или текущей системы |
| ЧТЕНИЕ | показывает оглавление/содержимое доступного файла |
| РЕДАКТИРОВАНИЕ | изменяет/записывает/переписывает файл |
| СОЗДАНИЕ / УДАЛЕНИЕ | создаёт/разбирает собственные небольшие виртуальные объекты; чужой объект удалить нельзя из-за защиты Создателя |
