## Сборка препарата

Проверка Фармацевтики делается против итоговой Сложности. Базовая сложность — сумма эффектов. Сила от 1 до 3 прибавляется к ней. Снижения за побочные эффекты вычитаются, но промежуточный результат не может быть ниже 2.

| Значение | Эффект |
|---:|---|
| 15 | REF + Сила |
| 15 | INT + Сила |
| 15 | COOL + Сила |
| 15 | Осведомлённость + Сила |
| 15 | лечение +1 пункт за единицу Силы |
| 15 | противоядие: +1 к спасброску за Силу |
| 10 | Выносливость + Сила |
| 10 | нивелировать боль: +Сила к спасброску оглушения |
| 5 | депрессант: −Сила к Осведомлённости |
| 5 | эйфория |
| 10 | галлюциноген |
| 10 | ослабить оглушение: +Сила к спасброску оглушения |
| 5 | снотворное: −Сила к спасброску сна |
| 10 | афродизиак: −Сила к сопротивлению Соблазнению |
| 10 | контрацептив |
| 10 | антибиотик: +Сила к спасброску заражения |

| Побочный эффект | Снижение | Точная механика |
|---|---:|---|
| Психологическая зависимость | −8 | каждый час после дозы `1D10 < COOL`; провал: тревога, страх или депрессия и только поиск дозы; лечение Выносливостью 25 |
| Физиологическая зависимость | −10 | каждый час `1D10 < BODY`; провал: сильная боль и 2D6 урона до лечения; Выносливость 25 |
| Смерть | −15 | при каждой дозе спасбросок смерти с −1 за единицу Силы |
| Снижение REF | −5 | REF −1 за дозу на срок действия; дозы складываются |
| Снижение INT | −5 | INT −1 за дозу; складывается |
| Тремор | −2 | REF −2 |
| Галлюцинации | −5 | практически не функционирует; для галлюциногена гарантирован плохой приход по решению Рефери |
| Паранойя | −3 | бросает прочие действия и защищается от «НИХ» |
| Бред | −5 | бросает прочие действия и поддерживает бред |
| Бесплодие | −8 | 3/10 |
| Канцерогенность | −10 | рак 3/10; при раке 1 постоянного урона; без Медтех 25 — смерть |
| Психическое расстройство | −10 | психотическая ярость, атака любого доступного |
| Агрессивное поведение | −12 | 5/10 начинает бой с ближайшим |
| Неконтролируемый страх | −12 | бросает всё, почти кататония до окончания |
| Нейродегенерация | −15 | постоянный REF −2 |

| Длительность | Множитель сложности |
|---|---:|
| `1D10+1` ходов | ×1 |
| `1D10+1` минут | ×2 |
| `1D10+1` часов | ×3 |

Итоговая сложность: **`(базовая сложность + Сила − побочные эффекты) × множитель длительности`**. Цена дозы: **`итоговая сложность × 25 eb`**; например, сложность 26 даёт 650 eb.
