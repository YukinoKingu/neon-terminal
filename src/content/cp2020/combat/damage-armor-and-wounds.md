## Попадание и броня

Неприцельное попадание определяет зону броском `1D10`; невозможную из-за укрытия зону перебрасывают. Прицельная атака в выбранную часть тела получает −4.

| Этап | Расчёт |
|---|---|
| 1. Зона | определить случайно или выбрать с −4 |
| 2. Защита | вычесть SP брони и укрытия зоны |
| 3. Пробитие | если урон ≤ SP, тело не получает урона |
| 4. Износ | пробившая атака уменьшает SP зоны на 1 |
| 5. Тело | применить BTM к оставшемуся урону, минимум 1 |

Каталожные SP и EV конкретной брони находятся в разделе брони и здесь не дублируются. EV всех надетых предметов суммируется и вычитается из REF.

## Слои и специальные типы урона

Разрешено не более **3 слоёв** и не более одного жёсткого. Второй слой добавляет EV −1, третий — EV −2. Подкожная броня и нательные пластины считаются слоями; прошивка кожи считается слоем, но не получает этот штраф.

Для двух защит вычтите меньший SP из большего, найдите бонус по разнице и прибавьте его к большему SP. Три слоя объединяются попарно изнутри наружу.

| Разница SP | Бонус к большему SP |
|---:|---:|
| 0–4 | +5 |
| 5–8 | +4 |
| 9–14 | +3 |
| 15–20 | +2 |
| 21–26 | +1 |
| 27+ | +0 |

AP-боеприпас делит SP пополам, а прошедший урон — ещё раз пополам с округлением вниз. Помеченная клинковая уязвимость означает половину SP против клинков.

|---|---:|
| Гипсокартон | 5 |
| Каменная стена | 30 |
| Дерево / телефонный столб | 30 |
| Кирпич | 25 |
| Шлакоблок | 10 |
| Деревянная дверь | 5 |
| Тяжёлая деревянная дверь | 15 |
| Стальная дверь | 20 |
| Бетонный столб | 35 |
| Data Term | 25 |
| Кузов / двери автомобиля | 10 |

## BTM и ранения

| BODY | BTM |
|---|---:|
| Очень слабый | 0 |
| Слабый | −1 |
| Средний | −2 |
| Сильный | −3 |
| Очень сильный | −4 |
| Сверхчеловек, только кибернетика | −5 |

Лёгкое ранение не даёт штрафов. Серьёзное даёт **REF −2**. При Критическом REF, INT и COOL уменьшаются вдвое с округлением вверх, при Смертельном — до одной трети с округлением вверх. Более 8 урона одной атакой в конечность отсекает или разрушает её и требует немедленного спасброска смерти как при Смертельном 0. Такое попадание в голову убивает автоматически; прочий урон в голову удваивается.

## Оглушение и смерть

Спасбросок оглушения: **`1D10 ≤ BODY + модификатор текущего ранения`**. Провал выводит персонажа из боя; бросок повторяют в следующих раундах, пока успех не вернёт его в действие.

| Ранение | Модификатор спасброска |
|---|---:|
| Лёгкое | 0 |
| Серьёзное | −1 |
| Критическое | −2 |
| Смертельное 0 | −3 |
| Смертельное 1 | −4 |
| Смертельное 2 | −5 |
| Смертельное 3 | −6 |
| Смертельное 4 | −7 |
| Смертельное 5 | −8 |
| Смертельное 6 | −9 |

При смертельном ранении каждый раунд выполняется **`1D10 ≤ BODY − уровень Смертельного`**. Провал означает смерть в конце раунда.
