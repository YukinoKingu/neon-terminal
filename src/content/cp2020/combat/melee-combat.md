## Встречная проверка

Атака разрешается как **`REF атакующего + навык + 1D10` против `REF защищающегося + навык + 1D10`**. Защита выбирает Боевые искусства, Фехтование, Ближний бой, Уклонение или Атлетику по ситуации.

| Приём | Механика |
|---|---|
| Удар рукой | `1D6/2 + модификатор урона` |
| Удар ногой | `1D6 + модификатор урона` |
| Блок / парирование | предотвращает или поглощает урон |
| Уклонение | −2 к попаданию атакующего |
| Разоружение | успешный бросок выбивает оружие |
| Бросок | требует предыдущего захвата; `1D6 + модификатор`, спасбросок оглушения −2 |
| Удержание | требует захвата; обездвиживает до успешного выхода |
| Выход | успешный бросок освобождает |
| Удушение | требует удержания или захвата в прошлом ходу; `1D6` за ход |
| Подсечка / перевод в партер | цель падает; −2 к её следующей атаке, +2 к следующей атаке исполнителя |
| Захват | подготавливает бросок, удушение или удержание |

## Боевые искусства

Ключевой приём стиля получает бонус +2…+4. К урону добавляется текущий уровень Боевого искусства сверх бонуса BODY. Стоимость улучшения уровня умножается на коэффициент сложности.

| Стиль | Сложность | Достоверно читаемые ключевые бонусы |
|---|---:|---|
| Карате | 2 | удар +2, блок/парирование +2, пинок +2 |
| Дзюдо | 1 | ячейки требуют визуальной сверки |
| Бокс | 1 | ячейки требуют визуальной сверки |
| Тайский бокс | 4 | ячейки требуют визуальной сверки |
| Чой Ли Фут | 3 | удар +2, блок/парирование +2, пинок +2, уклонение +1, подсечка +1 |
| Айкидо | 3 | ячейки требуют визуальной сверки |
| Звериное кунг-фу | 3 | ячейки требуют визуальной сверки |
| Тхэквондо | 4 | ячейки требуют визуальной сверки |
| Сават | 2 | ячейки требуют визуальной сверки |
| Борьба | 1 | ячейки требуют визуальной сверки |
| Капоэйра | 3 | ячейки требуют визуальной сверки |

Уклонение объявляется в начале хода: атаки против персонажа получают −2, а каждое его последующее действие — −3. При парировании весь урон сначала принимает объект; обычное оружие не ломается при `1D10 ≤ 9`, последующие действия также получают −3.

## Модификатор урона BODY

| BODY | Добавляемый урон |
|---|---:|
| Очень слабый | −2 |
| Слабый | −1 |
| Средний | 0 |
| Сильный | +1 |
| Очень сильный | +2 |
| 11–12 | +4 |
| 13–14 | +6 |
| 15+ | +8 |

Моноклинок, монокатана и Slice & Dice при атаке 10 наносят двойной урон, при сбое 1 ломаются, а при парировании ломаются при `1D10 ≤ 4`. SP мягкой брони против них равен одной трети, жёсткой — двум третям. Киберзверь делает одну атаку за ход с броском **`10 + 1D10`**; киберзмея наносит **1D6**.

## Неопределённости источника

### Группа uncertainty 3 — бонусы боевых искусств

На печ. 100 колонки разъехались. Надёжно сопоставлены только Карате и Чой Ли Фут; остальные бонусы не угадывались и оставлены для визуальной сверки.

### Группа uncertainty 7 — первые значения BODY

Первые пять чисел таблицы урона BODY потеряны OCR и восстановлены по последовательности. До визуальной сверки они остаются явно uncertain.
