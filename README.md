# NEON//TERMINAL

Неофициальный русскоязычный справочник для Cyberpunk 2020, построенный на Astro, Vue и TypeScript.

Проект находится на этапе технического фундамента. Рабочая документация хранится в [`Docs`](Docs/).

## Команды

```sh
pnpm install
pnpm check
pnpm build
```

Сервер разработки запускается в фоновом режиме:

```sh
pnpm astro dev --background
```

Остановить сервер:

```sh
pnpm astro dev stop
```
